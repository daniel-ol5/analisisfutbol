# Prueba integral desde la aplicación

La guía vigente es [GUIA_CALIBRACION_DINAMICA.md](GUIA_CALIBRACION_DINAMICA.md).

El orden actual para grabación es:

1. Crear un partido de prueba y subir su video.
2. Configurar reconocimiento automático para ese partido y video.
3. Solicitar procesamiento y ejecutar el worker.
4. Revisar detecciones, líneas estimadas, posiciones y estado de referencia.

Para directo, configurar otro partido con fuente Cámara en directo, guardar
el nombre de fuente e iniciar el encuentro antes de conectar el worker.

Los resultados y límites de las pruebas están en
[el informe de validación](docs/validacion/CALIBRACION-DINAMICA-2026-11-17.md).
